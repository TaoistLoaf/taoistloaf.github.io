## Hugo

- Generate a new post: `hugo new posts/my-first-post.md`
- Set `draft: false` when a post is ready to publish.
- Generate a new page: `hugo new about.md`

## Git

This source repository now uses a GitHub Actions workflow to build and publish the site, so generated HTML does not need to be committed by hand.
